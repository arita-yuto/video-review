すべての動画の最近のコメント・アップロード・リアクションを、1 か所で新しい順に見られます  
動画を 1 本ずつ開かなくても、前回見たあとに何があったかが分かります

---

## 1. Activity を表示

Video list の右にあるベルのボタンを押します

<img src="/video-review/images/features/activity/activity-button.webp" width="171" alt="Video list の右に並ぶベルのボタン" />

※ ゲストでログインしているときは、ベルのボタンが出ません

## 2. 種類で絞り込み

左のタブで、表示する種類を選びます

- All: すべて
- Comments: コメント
- Uploads: 動画のアップロード
- Reactions: コメントへのリアクション(👍️)

<img src="/video-review/images/features/activity/activity-dialog.webp" width="700" alt="Activity のダイアログ" />

## 3. 新着を確認

前回 Activity を閉じたあとの項目には New が付き、New の線より上が新着の項目になります  
Activity を閉じると、そこまでが確認済みになります

<img src="/video-review/images/features/activity/new-entries.webp" width="700" alt="New が付いた項目と New の線" />

## 4. 項目から動画を表示

- コメントとリアクションの項目を押すと、コメントが書かれた位置で開きます
- アップロードの項目を押すと、アップロードされたリビジョンで開きます
