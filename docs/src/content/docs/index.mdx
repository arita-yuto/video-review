<section class="vr-section vr-start">
    <h2>Quick start (Docker)</h2>

```bash
mkdir video-review
cd video-review
curl -L -O https://raw.githubusercontent.com/arita-yuto/video-review/main/compose.prod.yml
docker compose -f compose.prod.yml up -d
```

<p>Open <code>{"http://localhost:3489"}</code> and register the first administrator.</p>
