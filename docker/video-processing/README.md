# VideoReview video-processing

The thumbnail and transcode worker for [VideoReview](https://hub.docker.com/r/aritayuto/videoreview), a self-hosted, on-premise alternative to Frame.io for game and video teams.

It doesn't run on its own. See [aritayuto/videoreview](https://hub.docker.com/r/aritayuto/videoreview) to start VideoReview; the `compose.prod.yml` in its Quick start runs this worker alongside the web app.
