# Videos

動画の一覧を見て、動画やリビジョンのファイルを削除したり、CSV でまとめて移動・名前の変更をしたりします

<img src="https://github.com/user-attachments/assets/9c980229-863d-4654-8b34-ed2362e50782" />

## 1. 動画を削除する

1. 行の右の Delete を押します
2. 確認の入力欄に `Delete` と打ちます（大文字小文字も同じに）
3. Delete を押します


<img src="https://github.com/user-attachments/assets/209cb30a-41d3-4312-a7e5-9e6a20cd113c" />

※ 動画を削除すると、リビジョンも全て削除され、動画は一覧から消えます  
※ 同一フォルダーキー、タイトルをアップロードした場合、コメントなどは消えていないため、また閲覧できます

## 2. リビジョンだけ削除する

1. 矢印 `>` でリビジョンの一覧を開きます
2. 消したいリビジョンの Delete を押し、同じように `Delete` と打って確定します

<img src="https://github.com/user-attachments/assets/6703889a-dde5-4401-957f-b4b484d9be83" />

※ リビジョンを削除すると、そのリビジョンの動画を見ることができません

---

## 3. CSV でまとめて移動・名前を変える

動画の一覧を CSV に書き出し、フォルダーとタイトルを書き換えて読み込むと、移動と名前の変更をまとめてできます

### CSV に書き出す

一覧の上の Export を押すと、`videos.csv` がダウンロードされます

### CSV を編集する

| 列 | 内容 |
|---|---|
| id | 動画の id（書き換えない） |
| folder | フォルダーキー<br>書き換えると、その動画を別のフォルダーへ移します |
| title | タイトル<br>書き換えると、名前が変わります |
| files | リビジョンごとのファイルの置き場所（読み込むときは使わない） |

変えたくない動画の行は、そのままにするか、消してかまいません  
同じフォルダーに同じタイトルの動画は置けません

※ UTF-8 で保存します  
※ 移動・名前の変更のあとに、古いフォルダーキーとタイトルでアップロードすると、別の新しい動画になります  
※ CLI や Unity / UE から上げているときは、送るフォルダーキーとタイトルも合わせて変えます

### CSV を読み込む

1. 一覧の上の Import を押します

<img src="https://github.com/user-attachments/assets/16f92c07-0430-4c94-aa96-2189daebd915" />

2. CSV ファイルを選んで、Import を押します

<img src="https://github.com/user-attachments/assets/35f28b5b-a19d-4772-8044-c6a9ce8ca87d" />

取り込みに成功した場合、更新した動画の本数が表示されます  
エラーがある場合は何も反映されず、行・列・理由の一覧が出ます
